## 🔐 Security Note

**Sensitive data is automatically protected!**

When copying, these fields are redacted:
- `password`
- `token`, `api_key`
- `secret`, `private_key`
- `credit_card`, `cvv`, `ssn`

## 💡 Pro Tips

### 1. Use Command Palette for Everything
Don't memorize all shortcuts! Just press **⌘K** / **Ctrl+K** and search.

### 2. Shortcuts Don't Work in Input Fields
This is intentional! We never interfere with typing.
**Exception:** Form shortcuts (⌘S, ⌘Enter) work everywhere.

### 3. Learn Sequence Shortcuts
**G+D**, **G+O**, **G+M** are easier than **⌘Shift+D**!
No modifier keys = less hand strain.

### 4. Platform Auto-Detection
- **Mac:** Uses **⌘** (Command)
- **Windows/Linux:** Uses **Ctrl**

### 5. Role-Aware
You only see shortcuts you have permission to use.
Press **Shift+?** to see YOUR available shortcuts.

## 🚀 Getting Started

1. **Explore:** Press **⌘K** / **Ctrl+K** and browse available actions
2. **Learn:** Press **Shift+?** to see all shortcuts for your role
3. **Practice:** Start with navigation (**G+D**, **G+O**, etc.)
4. **Master:** Use forms and tables with keyboard shortcuts
